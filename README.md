# WibuStyle

A themed lifestyle or fashion landing page with multiple sections.

## Overview
This repository contains a front-end website with a stylish design, including pages such as the homepage, about section, FAQs, lookbook, and admin interface.

## Features
- Multiple static pages
- Fashion/theme-based design
- FAQ page
- Lookbook showcase
- Admin page
- Interactive JavaScript behavior

## Tech Stack
- HTML
- CSS
- JavaScript

## Getting Started
1. Clone the repository.
2. Open `index.html` in a browser.
3. Or start a local server:

```bash
python -m http.server 8000
```

Then access:

```text
http://localhost:8000
```
